# ADR_SITE_DEMAND：产出账的对手方——谁把货拿走了

- status: aligned
- verified_at: 2026-11-10
- verified_by: agent（用户拍板「消耗有对手方」）
- evidence: `world-client/src/world/site-output.ts`, `world-client/src/world/simulation.ts`, `world-client/src/settings/dengchao/pack.ts`, `world-client/test/site-output.test.ts`, `server/tests/test_world_changes.py`

## 1. 问题

上一版消耗是「每个产出场所每世界日自己扣一份」。账确实不再只涨，
但**没人拿走**：炭在账上凭空少一份，世界状态一个字不变。
`ADR_SITE_OUTPUT` 当时把这条写成「不做消耗链」，随后补了按日扣减，
仍然只是把数字改小——离「经济」差的是对手方。

## 2. 决策

- **需求方由设定集按场所声明**（`SettingSite.consumes`，闭集校验）。
  引擎不点名任何一个场所：换一本设定集就换一条链。
- **货从产出它的那个场所扣，不从需求方自己扣。** `settleDemand` 是纯函数，
  供给方由 `supplierOf` 给（多个场所产同一种时按 id 字典序取第一个），
  需求方按 `siteId` 排序处理——同一个账本算出同一个结果，不取决于
  `Map` 的插入顺序。
- **灯潮界的链是三条**（全在 `pack.ts` 里）：
  锅炉房出炭 → 叠浪楼烧炭、洗出衣裳 → 集市把衣裳卖成成交。
  于是产出账第一次有方向：炭的日常去处是浴池，衣裳的日常去处是集市。
- **缺货不欠账、不阻断作业**：扣到 0 为止，记一条 `supply_short`。
  世界缺货是一条事实，不是一笔债；炉子凉了，炉匠第二天照样搬炭。
- **两条新事件**：`supply_used`（拿到了）与 `supply_short`（没等到），
  落点是**需求方自己**（集市是坐标锚、叠浪楼是那栋楼），`actorId` 为 `null`
  ——把货用掉的是场所，不是某个人做成了什么。
- **没有 `consumes` 的世界不消耗。** 莞尔镇、旧夹具照旧只累积：没有需求方
  就没有「用掉」，不该凭空扣账。
- **场所加 `name`**（「叠浪楼」「炉底入口」）。事件文案是给人看的，
  `boiler_annex#1` 读起来像调试输出；译名属于设定集，引擎不内置译名表。

## 3. 不在范围

- **成交（`trade`）不进链条**：它是交易的结果，不是货。集市产出成交、
  也消耗衣裳，但没有人「消耗成交」——给它硬找一个对手方只会造出一个
  谁也不认的账。
- 不做价格、不做物资在场所之间流动的路径：货是划账走的，不是真的有人扛。
- 缺货没有后果链（不影响作业、不影响心情之外的任何判定），只进记忆与日报。

## 4. 代价与已知边界

- **事件量又涨一点**：一天最多两条（一正一负），实测三天 6 条 `supply_used`。
- **缺货靠产能差才会出现**：设定集里三个场所的产能足够时，`supply_short`
  可能几天都不出现——测试里为了走通这条路径，人为多要两份炭。
  也就是说：**正常运行下这条路径很少被真实触发**，这是产能设计的结果，
  不是没实现。
- **没有「有人要但没人产」的设定集校验**：`consumes` 指向一种没有任何场所
  产出的货时，世界每天报一次缺货，不会在装载期拒。这是有意的——缺货是
  世界事实；但写设定集的人要自己看一眼。

## 5. 验证

- `test/site-output.test.ts` 12/12：新增三条——
  `settleDemand` 纯函数（跨场所扣、缺货不欠账、无供给方、按 id 排序）；
  真世界三天（叠浪楼取炭、集市取衣裳、落点正确、供给够时不误报缺货）；
  人为吃光产能后真的报缺货且库存不为负。
- `server/tests/test_world_changes.py` 73/73：新增一条——
  `supply_used` / `supply_short` 都能写进事件账（`actorId` 为 `null`）。
- 记忆分量：`supply_short` 在场者 0.375 过 `T_write`（镇上真的出了状况），
  `supply_used` 0.2375 压在门槛下（一天两次的日常不必人人都记）。
- 全量前端 2672 通过 0 失败；服务端 572 通过 1 跳过；十一道闸门 11/11。
