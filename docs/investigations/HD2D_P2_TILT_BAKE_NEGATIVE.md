## 1. 判死证据

三个机位，同一世界、同一帧、`?dof=on`：

| 机位 | 坐标 | 远带构图 | 藏掉 ≥1000 后 | 放回后 px / 簇 / 最长 |
|---|---|---:|---:|---|
| 渡口 | 300,160 | 含水，无建筑 | 0 | 471 / 9 / 16.5 |
| 林地 | 200,400 | 树林 + 屋顶，无水 | 0 | **13,393 / 191 / 88.5** |
| 屋面 | 800,700 | 屋顶 + 煤场，无水 | 0 | 12,760 / 120 / 72.5 |

- 藏掉 ≥1000 后三机位全为 0：闭包本身没漏，糊图确实盖住了整条贴地带。
- 放回后林地 13,393 px：房子、窗框、招牌、灯笼、仓房的墙、摊位、两个村民，全部是锐利剪影浮在糊底上。**在这个机位上，屋顶和招牌的硬边不是残差，是主视觉。**
- 渡口那张之所以成立，唯一原因是远带里什么都没有——没有建筑、没有屋顶、没有招牌。

## 2. 三条可复用判断

1. **运行时焦外在这套栈上不可做。** Phaser 4.2.1 在本项目的渲染路径上跑 WebGL1（请求 `webgl` 上下文，WebGL2 的核心特性靠 shim 补），没有可用的运行时后处理管线；GeometryMask 在 WebGL 路径下只打警告、不生效。全屏景深需要的两条路——后处理、蒙版让位——都拿不到。
2. **深度不是 z，是逐行显示排序。** 场景深度按落地行推导，`Graphics` 不写 z；≥1000 的建筑与人物按落地行逐行交错。一张平面糊图不可能同时压在建筑上、垫在人物下。
3. **唯一可行形态「纯烘焙 + 行裁切窗」只在远带无静态建筑时成立。** 它把贴地层烘成一张图、按焦线裁切，因此只能处理「糊图之下」的层；远带里只要有建筑，就会露出锐边。远带有没有建筑由构图决定，引擎保证不了，所以它**不作为引擎能力，不设默认开关**。

## 3. 已确定可复用的部分（留在分支，等真消费者再单独提）

- **整数可分离 box blur，核尺寸反推式 `k ≥ ⌈C / T⌉`**（k 取奇数）：整数 box 的台阶梯度上限是 `C / k`，给定目标反差 T 可直接反推最小核，不靠预先拍档。
- **全图合成 + 双缓冲版本向量**：静态源按版本号判断是否需要重合成，不变则复用上一版缓冲、只交换指针。可复用于任何静态层加工。
- **`setCrop` 的坐标坑**：Phaser 的裁切坐标相对纹理原点，不是左上角；要写 `x = -displayOriginX + crop.x`，直接传裁切矩形会整体偏移。

## 4. 给后人的一行

**渡口 471 / 9 / 16.5 是「远带无建筑」的读数；林地 13,393 / 191 / 88.5 是「正常街景」的读数。两者差 28 倍，差的是构图，不是实现。**

## 5. 不再做什么

- 不做 P3；不换渲染顺序、不换 mask 方案、不引第三方后处理再试一遍。
- 不在主线引入 `?dof` 或任何等价开关。
- 不把本实验的读数当成「已知残留可接受」——它们是「这条路走不通」的证据。
