## 零、读数纪律（先落在证据目录里；比 ADR 的双读数要求更基础）

1. **每条渲染读数必须带全口径**：机位（x/y）· zoom · 带段/ROI（世界坐标）· 潮位 · 相位 ·
   视口（CSS 尺寸）· 冻结帧 · **载入种子** · **真实天气强度 `rainStrength`**（只记 `kind` 不算钉晴）。例：
   `覆盖 76.56%（机位 x368/y470、zoom1、x240..560×y435..535、1pp、满潮、夜、clear/rainStrength 0.000、now 12:03、seed 20261019、视口 1010×700、frame180）`。
2. **同一指标在同一棵树上只允许一套有效数字**。两套并存即为失败——本文件此前就栽在这条上：
   把 `39cff04` 的一次未钉种子采样（76.9% / 1.8 格）当成了本树的读数，还据此写了「未变坏」。
3. 没重跑过的数一律写「未复测」并注明出处树与提交，不再挂着当现状；换机位/带段/阈值/冻结帧/种子，
   必须新旧参数并列写出，不许只报新数、更不许为了对上旧数调松判据。
4. **载入种子必须钉，天气必须量到强度**。
   - 抖动源是**雨滴种子** `window.__RAIN_SEED__`（`render/weather.ts`）：页面每次载入取不同的值，
     雨点逐帧乱飘。脚本在 `initScript` 里**任何模块执行前**写 `window.__RAIN_SEED__ = seed`；
     页面入口另有 `?debug=1&debugPinSeed=<n>` 的同值 LCG（只影响 debug 层，不落存档、不进回放指纹）。
   - **`debugSetWeather('clear')` 只改 `kind`，不等于钉晴**：雨幕按 `WEATHER_FADE_MS = 5 世界分钟` 淡出，
     从第 170 帧量到第 180 帧只走了 10 世界秒，强度仍 ≈0.97——画面还在下雨。真晴判据写死
     **`rainStrength < 0.05`**；本文件用 `?now=720` 直接落在自然 clear 槽（初始强度 0）。
   - 不钉种子（雨态）的实测分布：覆盖 **75.94 / 75.63 / 76.88**（sd **0.53pp**）、
     暗带 **3.94 / 4.63 / 1.81**（sd **1.20 格**）。`76.9/1.8`、`75.9/3.9`、`75.6/4.6` 是**同一分布的三个采样**，
     不是三个状态，也没有哪个是异常值；三组都**未记录种子**，属**历史不可追溯采样**。
     未钉种子的读数只能写「某次采样」，不能进对比表。
   - 本轮只给 `check-lamp-band.mjs` 接入了种子与强度判据；`check-lamp-pool.mjs`、摊位 / 幌布 / 投影
     等脚本里的「晴」仍是只改 `kind`，其读数按本纪律只能算「某次采样」，待各自接入后复测。
5. **A/B 判定用「同协议判据带」；协议灵敏度另立一栏，只用于警告，不当阈值。**
   **判据带**来自同协议连跑（当前树、当前参数、**种子钉住 + 真晴 + 满潮**）的**实际散布**，不写「约」：
   | 指标 | 实测散布 | 判据阈（脚本最小分辨） |
   |---|---|---|
   | 夜街覆盖 | 76.56% ×3（seed 20261019）；跨种子 1/7/42 同样 76.56（0 差） | **0.08pp**（1 采样单位） |
   | 最长暗带 | 4.4375 格 ×3；跨种子 0 差 | **1 格** |
   | ΔY avg | 3.330pp ×3；跨种子 0 差 | **0.01pp** |
   | ΔY max | 7.392pp ×3；跨种子 0 差 | **0.01pp** |
   | 暗带位置 x | 471 ×3；跨种子 0 差 | **1 像素** |
   **该判据带只在「种子钉住 + 真晴（`rainStrength < 0.05`）+ 满潮」下成立。任一口径未钉，结论就回到
   「不可比」，不是把带宽放大**——未钉种子的 sd（0.53pp / 1.20 格）**不是带宽**。
   **任何 A/B 必须在同协议下做**：差异 **≤ 判据阈**写「**未检出差异**」；**> 判据阈**才可判「改好了 / 改坏了」。
   **协议灵敏度**（另立，只警告「不要混协议比较」）：
   | 协议变化 | 观测量偏移 |
   |---|---|
   | 未钉雨滴种子（雨态） | 覆盖 75.94 / 75.63 / 76.88（sd **0.53pp**）、暗带 3.94 / 4.63 / 1.81（sd **1.20 格**） |
   | 只 `debugSetWeather('clear')`、未等雨幕淡出 | 强度仍 ≈0.97，读到的是**雨态**，不是晴 |
   | 页面冷启动 + 帧时机 | 一次整页异常 **81.9%**（图未留存，复现不出；作废，不参与判定） |
   这些数是「改变协议会带来多大偏移」的警告，**不是判据带**；不得拿来解释同协议 A/B。
   **噪声来源判断**：钉种子 + 真晴后 3/3、跨 3 个种子逐项相同；**雨滴种子是唯一可查明的来源**。
   本脚本没有别的取墙钟的口子，headless 取整与相位插值都是整数表驱动。**同协议下未观测到其他来源，判据带按 0 差处理**。

### 三、口径与隔离

- **世界时钟**：三支动态只读 `snapshot.now`（世界毫秒），经 `world/lamp-motion.ts` 的纯函数算出；
不读 `Date.now`、不读 `performance.now`。关掉一支时该函数退化为常量。
- **钉死世界**：开局 `?world=dengchao&time=dusk&feed=off&ledger=off&debug=1&now=1075`（17:55），
冻住世界后只用 `debugStepWorld` 按世界毫秒推进（每步 100ms × timeScale），每一帧的世界时刻都钉死；
同一序列跑两遍逐像素比较。
- **隔离手段**（只为量灯，不代表世界里的它们不在了）：
村民钉到画面外 (2,2)；渲染潮位钉到 1.0（世界里那条潮汐照常走）；鸟 / 蝙蝠（`ambience-view`）隐藏——
它们也由世界时刻驱动，会在灯街 ROI 上留下像素差，混进来就分不清是灯在动。
- **逐像素哈希**：PNG 字节带编码器与元数据差异，不能用 PNG 的 sha256 判定确定性；
页面内用 `crypto.subtle.digest('SHA-256', RGBA)` 逐像素比较，解码页必须先落在同源 http 上。
- **夜街光带/光池必须钉种子、量到真晴、钉潮位**：`check-lamp-band.mjs` / `check-lamp-pool.mjs` 在
`initScript` 里先写 `window.__RAIN_SEED__ = seed`（页面入口同值走 `?debugPinSeed=`），再用
`?now=720` 落在自然 clear 槽，测完读 `rainStrength` 并以 **< 0.05** 判真晴，最后 `debugPinTide(1)`。
只调 `debugSetWeather('clear')` 不够：它只改 `kind`，雨幕要 5 世界分钟才淡出（见「零、读数纪律」第 4 条）。
注意 `debugSetWeather` **不是**到 `e807759` 才有：`e807759` 已在 `debug-panel.ts`、`SandboxScene.ts`
两处提供；真正缺这个口子的是 `39cff04`（它也没有 `debugPinTide` / `debugStepWorld` / `debugWeatherIntensity`）。
拿 `39cff04` 基线对同一份脚本跑时，`params.pinned` 记成 `false`、`rainStrength` 记 `null`，
只能凭 `?now=720` 的 clear 槽位判定；这是**已知缺口**，不是我没写。
- **灯灭残留为什么用同一页比**：不同页面开局的存活帧数不同，会带进另一处既有的逐页差异
（左下角雾 / 罩层，约 1%、max 10），混进来就分不清是不是灯池残留。同一页、同一世界时刻、
同一摆相位下比，才是真的「没有上一帧的光池留在这一帧」。

### 三、口径与隔离

- **depth 3.1 的来历**：铺装 1 / 潮水 3 / **落地投影 3.1** / 街面光池 3.2 / `sceneryDepth(row)` ≥1000 /
  人物 `altitude + footY + 8` / 摊位与构件 ≥1000 / 建筑 1400。影子只压在地面，不抢光池（3.2 先画），
  更不可能盖到人和摊位；既有 depth 公式一个字没改。常量在 `ground-shadow.ts` 的
  `GROUND_SHADOW_DEPTH`，单测钉住 `3 < depth < 3.2`。
- **为什么影子让到脚底下方 3 行**：`createVillager` 里既有的静态接触线占 `footY..footY+2`，
  且随人物容器在 depth ≥1000，永远盖在 3.1 层之上；影子若画在同一行，正午/清晨这种短影子会整条
  被接触线吃掉。现画在 `footY+3..footY+4`（`VILLAGER_SHADOW_ROW_OFFSET = 3`），三相位都看得见，
  同时鞋面像素（≤ `footY−1`）与接触线（既有，未改）都不碰。
- **人物脚下边界**：开 / 关帧差只在世界行 `footY+3..footY+4`（bbox 高 4 图像 px = 2 世界行 × 2 倍像素）；
  裁图里能看到「鞋 → 既有接触线 → 新的深色条纹」三层，鞋的轮廓没有糊。
- **隔离手段**：灯三支动态全关、摊位两件全关、幌布两件全关、烟关、鸟 / 湾面低雾隐藏、潮位钉 1、
  **天气钉晴**、DOM 叠层隐藏；人物那一页把其他人钉到画外 (2,2)，只留被钉在自己的格子的 v0。
- **读数与画面必须同源**：`debugGroundShadowUnits` 现在读 `pinVillagers(this.snapshot, pinned)` 后的快照，
  与 `renderSnapshot` 画的是同一份；否则会出现「影子画在钉住的位置、读数却是世界位置」，
  裁图会裁空（本轮就撞到过一次，已修）。
- **判据带与夜态**：本条用的是开 / 关像素差，同协议判据带实测 **0.00%（0 px）**——同刻两页全关 0 px、
  同一页跨 t/t+1s 0 px、暂停 0 px、确定性 13/13。正午 / 黄昏的摊位 **0.45% / 0.55%** 与人物
  **0.02% / 0.17%** 都**大于判据阈，可判定**。**夜态按设计不做投影（`span=0 / alpha=0`），
  0.00% 即预期值、不是测不出**；判据带只用于「应做而未检出」的情形。
