## 零、读数纪律（先落在证据目录里；比 ADR 的双读数要求更基础）

1. **每条渲染读数必须带全口径**：机位（x/y）· zoom · 带段/ROI（世界坐标）· 潮位 · 相位 ·
   视口（CSS 尺寸）· 冻结帧 · **天气是否钉住**。例：
   `覆盖 76.6%（机位 x368/y470、zoom1、x240..560×y435..535、1pp、满潮、夜、晴、视口 1010×700、frame180）`。
2. **同一指标在同一棵树上只允许一套有效数字**。两套并存即为失败——本文件此前就栽在这条上：
   把 `39cff04` 的基线采样（76.9% / 1.8 格）当成了本树的读数，还据此写了「未变坏」。
3. 没重跑过的数一律写「未复测」并注明出处树与提交，不再挂着当现状；换机位/带段/阈值/冻结帧，
   必须新旧参数并列写出，不许只报新数、更不许为了对上旧数调松判据。
4. **天气与潮位必须钉**（`debugSetWeather('clear')`、`debugPinTide(1)`）。新世界固定从 00:00 开局，
   但 00:00 这一槽的天气按**当日种子**排；雨天雨点又逐帧乱飘。实测同一棵树、同一份脚本、同一组参数
   两跑相差 **1.0pp 覆盖 / 2.1 格暗带**（avg 2.70↔2.67、max 8.97↔10.93pp）。不钉天气，读数只能算「那一次的样子」，
   不能当回归基线，也不能跨天、跨跑比较。

### 三、口径与隔离

- **世界时钟**：三支动态只读 `snapshot.now`（世界毫秒），经 `world/lamp-motion.ts` 的纯函数算出；
不读 `Date.now`、不读 `performance.now`。关掉一支时该函数退化为常量。
- **钉死世界**：开局 `?world=dengchao&time=dusk&feed=off&ledger=off&debug=1&now=1075`（17:55），
冻住世界后只用 `debugStepWorld` 按世界毫秒推进（每步 100ms × timeScale），每一帧的世界时刻都钉死；
同一序列跑两遍逐像素比较。
- **隔离手段**（只为量灯，不代表世界里的它们不在了）：
村民钉到画面外 (2,2)；渲染潮位钉到 1.0（世界里那条潮汐照常走）；鸟 / 蝙蝠（`ambience-view`）隐藏——
它们也由世界时刻驱动，会在灯街 ROI 上留下像素差，混进来就分不清是灯在动。
- **逐像素哈希**：PNG 字节带编码器与元数据差异，不能用 PNG 的 sha256 判定确定性；
页面内用 `crypto.subtle.digest('SHA-256', RGBA)` 逐像素比较，解码页必须先落在同源 http 上。
- **夜街光带/光池必须钉天气与潮位**：`check-lamp-band.mjs` / `check-lamp-pool.mjs` 在 ACTION 之前调
`debugSetWeather('clear')` 与 `debugPinTide(1)`。不钉的话，00:00 这一槽的雨会按当日种子变、
雨点逐帧乱飘，读数跨跑就差 1pp / 2 格（见「零、读数纪律」第 4 条）。
拿 `39cff04` 基线对同一份脚本跑时，基线没有这两个口子（`params.pinned` 会记成 `false`），
读数只能记实际天气（雨）——这是**已知缺口**，不是我没写。
- **灯灭残留为什么用同一页比**：不同页面开局的存活帧数不同，会带进另一处既有的逐页差异
（左下角雾 / 罩层，约 1%、max 10），混进来就分不清是不是灯池残留。同一页、同一世界时刻、
同一摆相位下比，才是真的「没有上一帧的光池留在这一帧」。

### 三、口径与隔离

- **世界时钟**：三件只读 `snapshot.now`，经 `world/stall-motion.ts` 的三个纯函数
（`stallClothSwayAt` / `stallCoverSwayAt` / `stallFireAt`）算出；与灯街同一只钟、同一套表驱动整数动画。
不读 `Date.now` / `performance.now`，不存上一帧。
- **雨态与 `weather-stalls` 同一判据**：`packed` 来自 `stallsPackedFor(weather) || sim.preCoveredToday()`，
与盖布落下同一来源。`packed` 为真时 `setting-scenery` 不摆棚布（`cloth && !packed`），由 `weather-stalls`
摆盖布；为假时反过来。任意时刻只有一件在摆，不会出现「盖布落下了、棚布还在飘」。
- **真实雨态怎么触发**：`debugSetWeather('rain')` 走世界自己的天气状态机
（`sim.enqueue({kind:'setWeather', weather})`），不是往画面贴雨点；`packed`、盖布、棚布都由这个世界状态推出来。
- **盖布为什么另用「晴天 + 强制已盖」量**：雨幕本身逐帧在动（雨也是世界时钟驱动），会把盖布的帧差淹没；
`debugForcePacked(true)` 用的是同一个 `packed` 判据，量的是盖布本身。真实雨态另给单帧 + 读数
（`stall-motion-rain.png` 与 JSON 的 `rain` 段）。
- **火光不写地面光池**：火盆画在柜台面，分两段——**焰心 `y+10..14`**（3px 宽实心），**光晕上沿到 `y+9.6`、下沿到 `y+15.2`**（整块受光范围 `y+9.6..y+15.2`）；只提亮柜台像素，不调用灯池。`debugLampPool` 仍是 2552，
地面取样 10×5 像素差 0.00%，开关差 0.43% 的像素全在柜台上沿。
- **返工叙事无法验证**：火盆最初画在地面（`y+16..18`），当时的读数是覆盖 76.9→73.8、最长暗带 1.8→3.9。
那组数是**未提交的中间态 + 旧口径未钉天气**，回溯不了，**无法验证**，不当作证据；能验证的只有现在这两条：
地面取样 10×5 px **0.00%**、`debugLampPool` **2552**。另外注意：**3.9 格**在今天的未钉天气口径下
本身就是本树/基线都能跑出的正常值（见本节「四」），不能再拿它当「改坏了」的判据。
- **隔离手段**：灯的三支动态全关（`debugLampMotion` 三 false）、村民钉到画面外、渲染潮位钉 1.0、
ambience 隐藏、DOM 叠层隐藏（`screenshot({clip})` 会把顶栏的在线状态/帧计数截进来，混进哈希就误判不确定）。
- **确定性怎么判**：同一页面序列（`only-cloth`，世界时刻 18:10:00 → 18:11:00）连续跑两遍，逐像素 sha256；
PNG 字节带编码差异，不作判据。

### 三、口径与隔离

- **只读世界时刻**：幌布经 `world/banner-motion.ts` 的 `bannerSwayAt` / `bannerShadowAt`，
烟经 `world/smoke-motion.ts` 的 `smokePuffsAt`；与灯街、摊位同一只钟（`snapshot.now`），
纯函数、表驱动整数动画，不读 `Date.now` / `performance.now`，不存上一帧。
- **幌布为什么用 2 世界秒一步**：周期 36 秒、步长 3 世界秒时，18:10:00 与 18:11:00 对三面（offset 0/4/8）
恰好都落在 `dx=0`，四组帧差会全 0。改成 `worldSeconds(2)`（周期 24 秒）后，t 全 0、t+1s 是 `[-1,0,1]`，
影子 `[-2,0,2]`——「在动」与「关掉为 0」才分得开。
- **影子与布同源、但多走 1px**：`bannerShadowAt` 用同一个摆相位，`shadowDx = swayDx * 2`，
所以「只投影」那一组在布身定住时仍有帧差；夜里 `span=0 / alpha=0` 直接 return，保护夜街扫描带。
- **烟至少两段不同速度**：三段 `stepMs` 为 **15000 / 10000 / 7000** 世界毫秒，对应 sway 2/4/6、rise 4/12/20、
宽度 6/10/14、alpha 0.16/0.12/0.08；越往上越慢、越宽、越淡——同一条烟柱里三段不同相位，不是整体平移。
- **烟不盖楼体**：`topSteam` depth **1399 < `seting-scenery.architecture` 1400**，楼体像素先画，
烟被盖住；四个楼体 bbox 里变化像素实测 **0**。炉底那柱源头从地面抬到楼顶之上（`smokeAnchorY=532`），
不会从楼体中间冒出来。
- **隔离手段**：灯三支动态全关（`debugLampMotion` 三 false）、摊位两件全关、村民出画、鸟（ambience）隐藏、潮位钉 1、**天气钉晴**、DOM 叠层隐藏。
另外：artbook 的「湾面低雾」三条 420×5 横条也按世界时刻横移，会把「烟关掉」的对照污染成 **0.73%**；
它不是烟，量烟前用 `debugHideBayMist(true)` 摘出去（与藏鸟同一类隔离），摘掉后关掉对照 **0.00%**。
- **确定性怎么判**：世界冻住后只用 `debugStepWorld` 推进；同一序列跑两遍，逐帧像素 sha256（13/13）。
