# 日卡 + 周视图（纯读）验证报告

## 结论

**能做，而且已经做出来了：只读，不改存法。**
日历抽屉把 `DayDigest` 读成「每天一行」：有没有事 / 几个人 / 哪一天不平静 / 那天大概发生了什么。
它只调 `dayDigests()`、`dayDigestOf()`、`factDigest()` 三个读方法，建卡与周视图都是纯函数；
`CURRENT_SCHEMA_VERSION` 仍是 5，`IMPORT_MAX_BYTES` 仍是 2 MB，`world.memory` 的字段一个没动。

边界先说清楚：**真实存档只到第 89 天**。90–120 天沿用上一轮离线实验的合成输入，
只用来验证读取口径与第 103 天反例，不代表真实世界。

## 4. 纯读证明

### 4.1 脚本（真实 90 天存档，`docs/evidence/mem-daycard/results.json`）

| 对象 | 建卡前 | 建卡后 | 相等 |
|---|---|---|---|
| `world.memory` | 1,430,508 B / `c1ae2ae6…` | 1,430,508 B / `c1ae2ae6…` | ✓ 逐字节 |
| 存档文件 | 1,664,523 B / `c3f0e0c7…` | 1,664,523 B / `c3f0e0c7…` | ✓ 逐字节 |

脚本把 90 天全量、30 天屏、7 天屏、周守卫反复跑了 5 轮，再取第二份快照；
两份 SHA-256 一致。存档文件全程只读。

### 4.2 浏览器（真实 90 天存档，`docs/evidence/mem-daycard/browser-real.json`）

在**同一段同步脚本**里：读 `localStorage` 原文 → 点开「日历」→ 再读原文。

| 对象 | 开关前 | 开关后 | 相等 |
|---|---|---|---|
| 存档原文 | 1,682,987 B | 1,682,987 B | ✓ |
| `world.memory` 快照 | 1,447,566 B | 1,447,566 B | ✓ |

读数 1,597,037 → 1,682,987，变的不是存档、是计量单位（UTF-16 码元 → UTF-8 字节）：
旧脚本量的是 `String.length`，新脚本量的是 `TextEncoder` 编码后的字节数；存档原文一份没变。

浏览器里的 1,447,566 B 比文件里的 1,430,508 B 多 17 KB，是**世界载入时的迁移/填充**
（发生在截图与开关之前），不是这一屏写的；开关前后的两份快照相同。
自动存档会和世界 tick 抢时间，所以证明使用同一同步块里的前后比较，而不是跨秒比较。

## 7. 这条读的是什么、读不到什么（有损边界）

**读得到**

- 每天的事件数（`digest.events.length`）、人数（`digest.people.length`）。
- 每天旗子（`flags`）：安静 / 社交 / 干活 / 争执 / 异常 / 大事 / 其他。
- 每天的行数覆盖（`beats` 求和），可判断 `timelineMissing`。
- 中档的异常原句（`anomalies`）与远档留下的指针（`pointers` → `factDigest().what`）。
- 周视图的按日旗子、不平静日、平静与否。

**读不到（有损边界）**

- **原话**：远档 `anomalies` 会被清空；没有指针时只剩粗描述，读不到当事人原句。
- **具体时刻 / tick**：日摘要没有时间戳；`beats` 只记每个事件有几行，不给顺序与时刻。
- **精确拍号**：能还原行数（第 89 天 68/68），不能还原「第几拍是谁做了什么」。
- **地点**：紧凑日的 `places` 会清空；面板不假装知道地点。
- **谁说了哪句**：`people` 只有人数/名单，没有把某句话钉到某个人。

## 8. 这屏能答 / 不能答

**能答**

- 「第 103 天出事了吗？」→ 有事，6 人，争执日，吵了一架。
- 「那周是不是一直很安静？」→ 不是；第 103 天有事，其余日安静。
- 「第 89 天有几个人、有没有事？」→ 10 人、有事、29 个事件、社交日。
- 「哪几天不平静？」→ 按日旗子直接筛 `di/an/ma`。
- 「这段日子大概在干什么？」→ 社交/干活/安静/争执的粗描述。

**不能答**

- 「第 103 天他们原话怎么说的？」→ 只有「争执」这句摘要，没有原句。
- 「争执发生在几点？」→ 日摘要没有时刻。
- 「第 89 天的第 17 拍是谁跟谁？」→ `beats` 只有行数，没有拍号与人物映射。
- 「那天的具体地点？」→ 紧凑日地点已清空。
