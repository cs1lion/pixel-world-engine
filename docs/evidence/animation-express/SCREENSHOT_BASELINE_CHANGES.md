## 口径

- 像素差 = RGBA 逐像素不同的格子数 / 总格子数；**PNG 字节 sha256 不作判据**。
- `r1-r2 / r2-r3 / r1-r3` 是三跑两两之间的同一张图差值；`0` 表示逐像素完全相同。
- 归类：**甲** 三跑 0 差；**乙** 三跑仍有差且差区为整片色阶常量位移（整片世界没停住）；
  **丙** 三跑仍有差且差区落在动画对象自身（走/站帧、表情、过渡帧）；**丁** 尺寸不同，不可比。

## 重录前置条件（本分支尚未执行重录）

**必须等合进 main 的**：`pwe-material` 线的 `pinShotState`（等站定 + 冻钟 + 钉潮位 + 钉相机/zoom/scroll + 钉 seed）。本分支不实现它。

**已落地的抓拍夹具（脚本层，不碰世界代码）**：
- `check-dengchao.mjs` / `check-creation.mjs` 支持 `EVAL_OUT`（默认值不变）；实跑证据：`EVAL_OUT=tmp/anim-verify/out` 跑 `check-dengchao` 后 `world-client/eval/screens` 无任何改动。
- `npm run verify:reset`（`scripts/reset-verify-state.mjs`）：幂等清 `tmp/verify-events/events.db`（含 wal/shm）与 `tmp/verify-memory/`，每跑前一步，不需要人工清理。
- `<script>-pixel-ledger.json`：每图一行 `file + 逐像素 sha256 + 尺寸 + now + tide + camera`，两跑外部逐条比对，不依赖脚本内 run1/run2。

**仍缺**：
1. 外部两跑的自动比对入口（现在只能人工 `file` 对齐两份 ledger）；
2. 5 张 legacy 的**最终处置待定**（补脚本产出 or 连引用一起废弃；文件暂留磁盘以免 `audit-citations` 出现未解析引用）；
3. 旧图统一改名 `*.prev.png` 的保留链（重录时执行）。

**重录后会损失**：丙类 18 张的逐像素判据失效（只剩「差分落在角色 bbox 内」的弱判据）；卡通感/主观观感用像素判据本就判不了；字节级「相同」再不能作证据；157 张旧 sha256 对比链断裂。
