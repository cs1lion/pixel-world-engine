## 2. 为什么去掉所有深色线

试过三种走法，前两种都退回了：

1. **留 `charcoal` 底座**：每 16px 一道暗边，整面墙读成「叠起来的四层花箱」。
2. **左缘画 1px `deepShade` 竖线当花架立柱**：`deepShade`（#1b303b）与地面几乎同色，
   重复之后读成「几块绿板之间的缝」，比不画更糟。
3. **全部去掉**：墙身连续，靠花团的疏密与叶隙做结构 —— 采用。

结论：**在这套 24 色板下，任何深色分隔线都会被读成缝**，因为墙身是绿、地面也偏暗，
没有中间明度可用。要用「线」做结构，得先有第 25 色（ADR），本轮不做。
