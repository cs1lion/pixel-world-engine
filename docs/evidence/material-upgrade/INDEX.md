# 材质层升级证据（material-upgrade）

本目录是 `feat/material-upgrade` 分支的可复现证据：四类材质（路面 / 空地·广场 / 房屋外立面 /
人物）在**同一机位、同一帧号**下的前后裁图与像素读数。所有图都在本仓内，不引用仓外临时目录。

## 怎么复现

```bash
# 1) 该分支的 dev server（不要用 5188：那是别的工作树的端口，串台过两次）
cd world-client && npm run dev -- --port 5191 --strictPort

# 2) 抓前后两套；标 sheet 的取景点写在 material-capture.mjs，裁图坐标写在 material-analyze.py
node scripts/material-capture.mjs --label before     # 需在基线代码上跑（git stash 后再跑）
node scripts/material-capture.mjs --label after
python scripts/material-analyze.py before
python scripts/material-analyze.py after             # 顺带产出 ../compare/<目标>.png
```

- **取景**：`material-capture.mjs` 只拍整幅画布（480×320 世界像素 = 960×640 CSS），记下
  `scrollX/scrollY` 与 `cssPerWorld`；裁切在 Python 侧按**世界坐标**做。取景坐标只有一处，
  前后两遍必然逐像素对齐（相机 `centerCameraOn` 会被世界边界夹住，靠实际 `scroll` 换算）。
- **帧号**：脚本把 `requestAnimationFrame` 的 dt 固定为 1/60，并跑到第 240 帧再截。
  村民姿势、摊位火光相位因此逐像素可复现。
- **叠层**：只 `display:none` 顶栏/小地图/调试面板，**不改画布尺寸**（Phaser 监听 resize，
  改尺寸会重排取景）。

| villager | 49→51 | 13.11→13.34 | 27.66→28.01 | 0/0（裁窗非整格） | 80.70→80.81 |

口径：

- `textureEnergy` = 相邻像素亮度差的平均；平涂趋近 0，有接缝/纹理才抬升。
- `edgePct` = 亮度差 > 3 的相邻对占比，衡量结构线密度（防「脏、花」的抓手）。
- `逐格重复` = 按 16px 整格切分后不同格的个数 / 总格数；`9/9` 即每格都不一样。
- **`onToken` 在灯潮界一律 0%**：昼夜叠色把整片像素挪出了 palette 闭集，精确色槽匹配
  只对默认世界有效（`wall-default` 95.9%）。所以灯潮界的读数不看 `onToken`，
  看相邻差（`textureEnergy` / `edgePct`）与逐格重复率。

## 确定性读数

`node scripts/material-determinism.mjs after` 把 `performance.now` 钉成常量、帧号停在 240，
再隔 1 真实秒截第二张；另开一页跑到同一帧号截第三张。

| 项 | 本分支 | 基线 `39cff04` |
| --- | --- | --- |
| 冻结世界 1 真实秒：全画面帧差 | 0/614400 = 0.00% | 0.00% |
| 冻结世界 1 真实秒：ROI（480×320）帧差 | 0/153600 = 0.00% | 0.00% |
| 同上两张的 sha256 | 相同 | 相同 |
| 同一帧号两遍运行 | 936/614400 = 0.15% | 1080/614400 = 0.18% |

「同一帧号两遍运行」的 0.15% 是**引擎既有**的：载入期有 `Date.now()` 参与种子，
两遍会有同量级的散布，基线是 0.15–0.18%。材质层本身没有引入任何时间/随机源
（全部由 `hash2`/`seedOf` 派生、烘焙在载入期一次完成）。

## 约束读数（本机实测）

| 项 | 基线 `39cff04` | 本分支 |
| --- | --- | --- |
| 默认世界 noon 指令 / Graphics | 15482 / 27 | 15482 / 27 |
| 灯潮界 noon 指令 / Graphics | 15127 / 49 | 16686 / 49 |
| 灯潮界黄昏+雨 指令（上限 29000） | 19455 | 21014 |
| `debugLampPool`（灯亮满潮） | 2552 | 2552 |
| `lamp-band` 覆盖 / 最长暗带 | 75.9% / 3.9 格 | 75.9% / 3.9 格 |
| `lamp-band` 2 格 ΔY | 0.54 pp | 0.54 pp |

两条必须说清的口径差：

1. 任务书里给的 `lamp-band` 基线是 **76.9% / 1.8 格**，但在本 worktree 里把代码
   `git stash` 回 `39cff04` 重测，得到的是 **75.9% / 3.9 格**（同一台机器、同一端口、
   同一脚本）。所以这里以「本机基线与改后相等」为不回归的判据，而不是拿 76.9% 套。
2. 灯潮界每帧指令 **+1559**：材质全部加在**常驻 Graphics**（店面、板壁楼、街面铺装），
   它们每帧重放。地形那一层是烘焙贴图，加多少都不进每帧——所以路面的三档色阶/
   石粒/受光唇的代价是 0。默认世界没有这两类常驻材质，指令不变。
