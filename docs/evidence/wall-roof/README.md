# 花径石垣 · 瓦顶 · 2026-11-09

设定集 p110–111 的「石垣」原有的一件事：瓦葺压顶。上一笔（`docs/evidence/stone-wall/`）
只做到「笠石压顶」，把瓦顶留成了待办；这一笔把它补上。

**依据等级仍是 B**：只有仓库转述，没有一手画册证据（本机画册 PDF 99 页、无文字层，
对不上 p110–111）。所以这是「按『石垣 + 瓦顶』推的近形」，**不宣称还原设定集**。

**范围只有一处改动：石垣纹理顶上那 3px。** 墙高仍是 16px、件数仍是 8、`kind` 不变、
每帧 0 条、24 色不新增、**不新增纹理**（换掉的是石垣原有那两张的上 3px）。

## 1. 为什么只换 3px、不加高

加高 4–6px 能画出「出檐 + 瓦垄」两层，但这套投影里高度就是屏幕上的竖直像素：

- 墙在 `y20` 行，往上加高会伸进 **`y19` 那一行北篱**（O0：北篱 `x2..11 y19..20`），
  与树篱的像素互相压；
- 花床在墙的南侧，墙每高一 px，花床后的视线就少一截——上一笔选「齐腰」正是为这个。

所以这一笔只在原 3px 里换画法。代价写在明面上：**「瓦」只剩一层明暗可读**，
4px 一垄的沟在 1:1 下只是纹理，不是轮廓。

## 2. 定稿形制（16×16，顶上 3px）

| 行 | 画法 | 作用 |
|---|---|---|
| 0 | `stone` 压 **0.55** | 瓦脊受光的一道棱——**墙头在哪**的唯一线索 |
| 1–2 | `charcoal` 实色 | 暗瓦面 |
| 1–2 | `ink` 0.5，每 **4px** 一竖到底 | 瓦垄沟 |
| 3 | `ink` 0.3（原有） | 出檐影，瓦面与墙身的分界 |

墙身的砌缝、墙脚影、两版按 `x` 奇偶交替——**一个字没动**。

## 3. 试错：四个画法 + 一次重放，每一版都抓了图

| # | 画法 | 1:1 下的读法 |
|---|---|---|
| v2 | 暗瓦面 2px，**垄背错半垄压 1px 亮块**；檐口 `pale` 0.4 | 瓦垄读成**一排白齿**（锯齿）；檐口太亮，整道顶断成「暗帽 + 白梁」 |
| v3 | **亮瓦脊**（`stone` 0.55）+ 暗瓦面 2px + 4px 沟；檐口交给原有的出檐影 | **成**：亮脊 / 暗面 / 影三行，1:1 下读成「墙上有道瓦顶」 |
| v4 | 暗瓦面 3px（顶行不描亮）+ `pale` 0.35 檐口 | 暗瓦面**融进深色背景**：墙头没有边界，整道墙看着矮了一截 |
| v5 | v3 原样重放 | 与 v3 逐像素 **0 差**（确定性） |
| v6 | v3 但瓦面换 `water`（#294f60） | 读成**一根蓝杆**——色相比瓦更像水/漆，与石族脱节 |
| 终版 | v3 + 注释 | 与 v5 逐像素 **0 差**（只改注释，没动像素） |

两条可复用的经验：

1. **顶行必须描亮。** 暗瓦面直接贴着深色背景时，墙头会消失（v4）；「瓦」能不能读出来，
   首先取决于墙头还在不在，其次才是瓦垄纹理。
2. **2px 高的暗带上，明暗错位会读成锯齿。** 瓦垄只能靠**竖沟**（一色到底）暗示，
   不要在 2px 里塞高光块——1:1 下那是一排白点，不是垄背受光（v2）。
