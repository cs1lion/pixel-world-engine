# 像素世界运行时与造物主引擎：补充架构设计 v0.2

**关联文档**：
- **第一组（内环 · 自治运行时）**：《世界记忆协议 v0.1》、《单位间感知与信息传播设计》
- **第二组（外环 · 生成与受控演进）**：《造物主引擎：可行性评估》、《渐进迭代：自治等级与收敛条件》

> **核心定位**：本文档旨在补齐两组协议内部的链路断点，并打通“运行时记忆传播”与“造物主渐进迭代”之间的跨层反馈闭环，构建一套**内环零/低模型调用确定性运转、外环带自动化门禁收敛**的双环控制系统。

## 0. 架构总览：双环控制结构

整个像素世界引擎由两个相互咬合的控制环组成：

1. **内环（记忆 $+$ 感知传播）—— 确定性状态机**：
   以只追加的事件日志（Event Log）为唯一真相源。在即便完全断开外部大模型的极端情况下，世界依然能依靠显著度（Salience）公式、空间痕迹沉积（Trace）和社交图谱扩散规则，自洽、低成本、$100\%$ 可回放地运转。
2. **外环（造物主 $+$ 自治爬梯）—— 受控编译器**：
   仅在“创世构建”与“每日低频节点（`DayClosed`）”介入。将模糊的设定资料与人类的审美批注，通过可计算的检查门禁（Computable Metrics），源源不断地编译为内环可执行的**确定性资产**与**不变式护栏（Invariants）**。

## 1. 第一组补充设计：世界记忆 $\times$ 感知与信息传播（内环）

本节聚焦于解决三个交界处问题：**信念冲突如何转化为可见的像素行为**、**静态空间痕迹如何反向激活八卦传播网**，以及**上游 Personal Agent 的隐私任务如何安全映射为世界叙事**。

### 1.1 “认知失调 $\rightarrow$ 主动求证”的行为闭环（Belief-to-Action Bridge）

在现有协议中，单位收到传言（`ClaimTold`）后可选择“采信、存疑、核实或拒绝”，但缺少一个不依赖大模型调用的**确定性求证触发器**，将静态的数据冲突转化为地图上的跑动演出。

- **认知失调触发公式（纯规则计算）**：
  当单位收到一条关于事件 $E$ 的 `ClaimTold`（生成候选 `heard` 记忆），且与其记忆库中已有的 `witnessed` 记忆或高置信度 `Belief` 发生冲突（如同一 `event_ref` 的情绪效价 `valence` 正负相反，或 `outcome` 关键字段互斥）时，计算求证冲动值：
  $$\text{Impulse}_{\text{verify}} = \text{salience} \times |\Delta \text{valence}| \times \text{rel\_trust}$$
- **空间化求证行为注入**：
  当 $\text{Impulse}_{\text{verify}} \ge T_{\text{verify}}$ 时，系统不直接覆写信念，而是向该单位的行为决策层注入一个高优趋避修正项（Modifier）：
  1. **寻路核实**：驱动像素小人放下手头低优杂务，主动寻路前往事发地点 `place_id` 或城镇 `公告栏/档案室`。
  2. **现场交互与状态收敛**：
     - 若在事发地目击到对应的物质痕迹（`Trace`），或在公告栏读到官方通告（`AnnouncementRead`），则将原 `heard` 记忆升级为 `witnessed / read`，置信度拉满；
     - 若现场完好且与传言严重不符，则触发 `RumorDebunked(claim_id, verify_actor)`，并在头顶弹出辟谣气泡。

### 1.2 “空间沉积（Trace） $\rightarrow$ 溯因推断（Inferred Claim）”规则表

为遵守《世界记忆协议》“写入与检索路径 $0$ 次模型调用”的成本预算，同时兑现《信息传播设计》中“第五通道：痕迹（路过并注意到的人需推断）”的设计，引入**确定性溯因查表机制（Abductive Lookup Table）**：

- **触发时机**：不在场（非 `witnesses`）的单位路过某地点触发 `CueFired(place_id)`，且该地点存在高可见度的新增 `Trace`，而该单位记忆库中无对应 `event_ref`。
- **查表生成残缺记忆**：
  直接按规则表生成一条 `source_mode = inferred`、`detail_level = 1` 的残缺记忆条目与低置信度断言（`Claim`）：

| 观察到的地点痕迹 (`Trace.layer_type`) | 生成的推断记忆 (`content.what`) | 初始字段特征 | 后续传播驱动力 |
| :--- | :--- | :--- | :--- |
| **焦痕 / 修补木板** | “此处近期发生过事故或冲突” | `who: []`, `confidence: 0.35`, `surprise: 0.8` | 极高的 `surprise` 与缺失的 `who` 字段，会驱动该单位在进入酒馆（闲话枢纽）时优先发起询问，从而用纯规则激活城镇八卦链 |
| **花环 / 彩带装饰** | “此处近期举办过庆典或受过嘉奖” | `who: []`, `confidence: 0.50`, `valence: +0.5` | 产生正向趋近修正（偏爱路过此处） |
| **磨损小径 / 固定座位** | “有人长期高频在此往返劳作” | `who: []`, `confidence: 0.60`, `kind: habit` | 沉积为对地点繁忙程度的长期印象 |

### 1.3 上游 Agent 隐私事件的“隐喻脱敏编译器”（Sanitized Metaphor Compiler）

针对上游 Personal Agent 处理用户私人邮件、本地代码或财务文档（`visibility = private_to_player`）时，若直接屏蔽会导致像素世界“无事发生、无人说话”的痛点，在上游事件进入世界契约前增设一层**结构化脱敏映射器**。

- **脱敏原则**：剥离一切自然语言实体与业务敏感词，仅提取**“工作流拓扑状态 $+$ 情绪效价（Valence）$+$ 持续时长/重试次数”**，编译为像素世界本土的 `sanitized` 事件：

| 上游 Agent 真实事件 (`private_to_player`) | 编译后的世界 Event (`visibility: sanitized`) | 世界侧的记忆、传播与痕迹表现 |
| :--- | :--- | :--- |
| 解析加密 PDF 财报连续报错 $3$ 次 | `kind: conflict`, `place: 藏书阁`, `outcome: {obstacle: "sealed_scroll", retries: 3}` | 学者写入高挫败感 `Episode`；酒馆流传“藏书阁挖出打不开的禁书”；藏书阁外墙叠加一层“修补/焦痕” `Trace` |
| 并发调用 $5$ 个网页检索工具耗时过长 | `kind: expedition`, `place: 迷雾哨塔`, `outcome: {concurrency: 5, duration: "long"}` | 斥候生成 `flashbulb` 闪光灯记忆；路过哨塔触发疲惫气泡；公告栏张贴远征通告 |
| 用户在验收抽屉一键“准奏”合并代码 | `kind: celebration`, `place: 中央祭坛`, `outcome: {blessing: "golden_seal"}` | 参与者获得高正向 `valence` 记忆强化；对应工坊挂起庆典花环；多次发生后晋升为集体传说（`Legend`） |

### 1.4 传播护栏的“自适应阻尼器”（动态熵调节）

为防止固定阈值（`T_write`、扇出上限、冷却时间）在任务高峰期导致“全村瞬间全知（信息过热）”，或在空闲期导致“全村死寂”，引入基于滑动窗口的动态阻尼调节：

- **过热抑制**：统计过去半个 `world_day` 内的全局 `ClaimTold` 触发频次。当逼近单日传播预算上限时，线性拉高闲话传播的显著度门槛 $T_{\text{gossip}}$ 与单人冷却时间。
- **冷清激活**：当世界连续半天无新增高显著度 `Event` 时，自动下调 `CueFired` 的回忆触发阈值，促使像素小人在相遇时翻出 `long`（周摘要）或 `legend`（传说）层级的旧事进行复述，维持世界呼吸感。

## 2. 第二组补充设计：造物主生成 $\times$ 渐进迭代与自治爬梯（外环）

本节聚焦于解决：**如何让每次人工介入真正沉淀为机器护栏**、**当系统出现长程漂移时如何自动收紧权限**，以及**如何用工程手段绕过 2D 像素接缝与动画生成的短板**。

### 2.1 收敛条件工程化：逆向审校合成器（Diff-to-Rule Synthesizer）

《渐进迭代》要求“每次人工修改都沉淀成规则、示例或提示模板”，但人类在验收（Review）时往往习惯“直接动手改结果”而非“手写规则”。为此，在人工确认点后挂载一个**异步的逆向审校器**：

1. **差异捕获**：每当人类在 L1/L2 检查点修改了造物主的提议（如微调了 `世界圣经` 字段、挪动了地图建筑坐标、或驳回了某张精灵图），系统自动记录二元组 $(\text{Proposal}_{\text{agent}}, \text{Diff}_{\text{human}})$。
2. **规则提炼**：逆向审校器对比差异，自动拟定一条可计算的约束补丁或负向示例：
   - *空间/布局修改* $\rightarrow$ 提炼为空间拓扑约束（如：检测到人类将铁匠铺移近水源，自动拟定规则 `distance(iron_workshop, water) <= 3`）；
   - *美术/色板驳回* $\rightarrow$ 自动提取被拒图片的边缘杂色或色板偏移特征，更新自动检查器的量化阈值；
   - *文本/历史修改* $\rightarrow$ 提炼为新的世界圣经不变式（Invariant）或禁用词条。
3. **一键固化**：人类无需编写规则代码，只需对面板弹出的气泡提示（*“是否将刚才的修改固化为【地图师】的永久校验规则？”*）点击 **【确认固化】**，即可完成源头治理。

### 2.2 自治爬梯（L0–L4）的双向熔断与降级状态机

自治等级不应只是单向晋升，还需具备根据线上质量实时收紧的**熔断降级机制（Circuit Breaker）**：

```
[L1: 逐项人工确认]  ===(连续 N 轮修改率 < 阈值 & 自动检查全绿)===>  [L2: 过检免审 / 异常人工]
       ^                                                                    |
       |                                                                    v
[自动熔断降级] <===(触发：摘要校验拒绝率飙升 / 不变式冲突 / 人工回滚)=== [L3: 抽检放行]
```

- **降级触发器**：为每个造物主角色（尤其是运行期的 `导演` 与 `史官`）绑定滑动窗口健康度指标。一旦在连续 $K$ 个 `world_day` 内出现：
  1. 《世界记忆协议》中的日摘要校验拒绝率（实体越界回退）超过阈值；
  2. 《信息传播设计》中的辟谣率或信念冲突率异常失控；
  3. 玩家触发了分支回滚（Rollback）或级联删除（`MemoryDeleted`）。
- **熔断执行**：系统自动将该角色的自治等级从 L3/L2 降级回 **L1（强制人工确认）**，并在主时间线旁自动切出一条隔离沙盒分支（Branch），直至回归集回放测试重新达标。

### 2.3 绕过接缝与动画瓶颈的“三层资产解耦架构”

针对评估表中指出的“AI 极难直接生成无缝瓷砖集（Tileset）与稳定序列帧动画”的客观物理限制，采用**几何确定性、纹理受控生成、动态靠记忆痕迹叠加**的三层解耦方案：

| 资产层级 | 生产与控制机制 | 目标自治等级 | 工程优势与效果说明 |
| :--- | :--- | :--- | :--- |
| **底层：拓扑骨骼与掩码层**<br>*(Base Grid & Rig)* | **$100\%$ 确定性算法与预制掩码**<br>（Auto-tile 47 格标准位掩码 + $16\times 16$ 通用小人裸模动作序列） | **L4（免审）** | 彻底根除“瓦片接缝错位”与“走路帧闪烁变形”问题，物理碰撞与寻路网格永远 $100\%$ 严丝合缝 |
| **中层：风格皮肤与纸娃娃组件**<br>*(Modular Skins & Props)* | **受约束生成 $+$ 强指标门禁**<br>（仅生成静态建筑本体、$8\times 8$ 工种帽子/手持物叠层、色板量化贴图） | **L2（过检免审）** | 自动检查器只需校验“像素尺寸、透明通道、色板重合率、剪影区分度”四项硬指标，无需人工逐张修图 |
| **表层：运行时叙事装饰层**<br>*(Runtime Narrative Traces)* | **由《世界记忆协议》的 `TraceSpec` 规则驱动**<br>（焦痕、青苔、修补木板、庆典花环、地名牌演变） | **L3–L4（规则驱动）** | **用“时间沉积的叙事细节”替代昂贵的逐帧动画**。每个世界的独特感来自真实历史事件留下的视觉痕迹，且 $100\%$ 可溯源、可回滚 |

## 3. 跨组咬合：记忆与传播指标作为“导演 Agent”的 PID 传感器

如何让造物主中的 **「导演（Director）」** 角色在长期运行中既不破坏玩家意图，又能精准控制世界节奏？核心原则是：**严禁导演直接阅读全量原始日志拍脑袋，而是将第一组（记忆与传播）的每日统计聚合值作为导演的“传感器输入”**。

### 3.1 每日“世界心电图”指标汇总

在每日 `DayClosed(day)` 完成日终整理（`MemoryConsolidated`）后，运行时自动提取以下 $4$ 个纯标量指标喂给导演角色：

1. **情绪均值（$\mu_{\text{valence}}$）**：全村活跃单位当日新增记忆的平均情绪效价（范围 $[-1, 1]$）。
2. **世界唤醒度（$\mu_{\text{arousal}}$）**：当日事件的平均兴奋度与显著度均值（判断世界是处于高压过载，还是无聊死寂）。
3. **社交孤岛指数（Isolation Ratio）**：关系图中连续 $M$ 天未发生任何 `ClaimTold` 交互的单位占比。
4. **未决流言热度（Unverified Rumor Count）**：当前传播网中处于高传播度（`reach`）但低置信度（`confidence`）的悬疑断言数量。

### 3.2 导演的参数化受控注入

导演角色根据上述“世界心电图”，只能从受校验的**创世指令库**中选择参数化动作（而非自由编造剧情）：
- 当 $\mu_{\text{valence}} < -0.4$（如近期上游 Agent 频繁报错导致世界内事故频发、士气低落）$\rightarrow$ 导演在次日排程中注入一场 `酒馆小型庆典` 或 `神明赐福通告`，温和拉回情绪基线。
- 当 `Isolation Ratio` 偏高 $\rightarrow$ 导演触发一次跨工坊的 `物资协作调拨事件`，强制激活孤岛节点的空间移动与当面交互。

## 4. 补充验收测试与落地优先级

在《世界记忆协议 v0.1》第 17、18 节的基础上，补充以下跨层联调验收断言：

| 测试项 | 验收断言（Assertions） |
| :--- | :--- |
| **脱敏零泄露** | 注入 $100$ 条含敏感词的 `private_to_player` 上游 Agent 事件，世界侧产生的 `Episode`、`Trace` 与气泡中敏感词命中率必须为 $0\%$，且情绪效价方向与原事件一致 |
| **求证行为闭环** | 注入一条与目击者记忆矛盾的 `ClaimTold`，当 $\text{Impulse}_{\text{verify}} \ge T_{\text{verify}}$ 时，单位必须在 $N$ 个 tick 内产生寻路至 `place_id` 或公告栏的位移指令 |
| **逆向规则沉淀** | 模拟人工在 L1 阶段连续修改 $3$ 次同类空间布局，逆向审校器必须成功提取出对应的结构化约束并写入自动检查器，第 $4$ 轮同类违规在人介入前被 $100\%$ 拦截 |
| **漂移自动熔断** | 人为向 L3 阶段的 `史官/导演` 注入越界实体，触发连续校验回退后，系统必须在当次 `DayClosed` 自动将其自治等级降回 L1 并切出隔离分支 |
