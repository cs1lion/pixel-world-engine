# 像素世界运行时与造物主引擎：补充架构设计 v0.2

**关联文档**：
* **第一组（内环 · 自治运行时）**：《世界记忆协议 v0.1》、《单位间感知与信息传播设计》
* **第二组（外环 · 生成与受控演进）**：《造物主引擎：可行性评估》、《渐进迭代：自治等级与收敛条件》

> **核心思想一以贯之**：
> 1. **真相与提议解耦**：事件日志与规则层是唯一真相。LLM 只做“理解与提议”，绝不直接持有或篡改世界状态。
> 2. **受限与失真受控**：没有全知视角，没有凭空编造。世界的生动感来自“有限视角下的局部偏差”与“时间沉积的痕迹”，而非高成本的实时模型生成。
> 3. **守护人类注意力**：验证的终极目的不是让人读完每一行产出，而是把人的判断持续编译成机器的可计算护栏，让系统在长程迭代中真正收敛。

---

## 0. 顶层图景：内环确定性运转 × 外环受控收敛

这两组文档实际上构成了整个系统的**双环控制结构**。补充设计的首要目标，是确保两环各自闭环，且在交界处保持纯粹的契约交互：

| 维度 | 内环：记忆与感知传播（Runtime） | 外环：造物主与自治爬梯（Build & Evolution） |
| :--- | :--- | :--- |
| **设计哲学** | **零/极低模型调用的确定性状态机** | **带自动化门禁的渐进式编译器** |
| **真相边界** | 事件日志是唯一真相；记忆与信念只是带出处的局部主观视图 | 设定包（世界圣经）与不变式是唯一基准；生成物只是待校验的候选提议 |
| **核心矛盾** | 如何在不调模型、不破坏确定性回放的前提下，让世界涌现出细腻的社会与叙事反馈？ | 如何在模型能力有限（如接缝、动画弱）与人类注意力稀缺的前提下，让迭代收敛而不漂移？ |
| **跨环咬合点** | 向外环输出**聚合态的世界心电图**（情绪均值、传言饱和度、校验拒绝率） | 向内环注入**受校验的创世指令**、静态规则表与固化后的不变式护栏 |

## 第一部分：记忆 × 感知传播（内环补充设计）

> **思想锚点**：内环写入与检索路径必须坚守“0 次模型调用、100% 溯源、只丢细节不编造事实、可确定性回放”的铁律。一切生动感必须从**视角差、信息差与空间沉积**中靠规则自然长出来。

### 1. 视角差驱动行为：从“信念冲突”到“在场求证”
《传播设计》定义了听者收到传言后可“采信、存疑、去核实”，《记忆协议》严格区分了 `witnessed`（亲历）与 `heard`（听说）。为了不把“存疑”做成黑盒的 LLM 心理戏，我们将其转化为**空间与在场（Presence）的物理闭环**：

* **思想逻辑**：既然“在场”是获取高置信度真相的唯一途径，那么消除“听说（低置信度）”与“固有记忆”之间冲突的唯一方式，就是**驱动单位肉身前往事发地或权威源头**。
* **确定性机制**：
  1. 当单位收到一条 `ClaimTold`，若其内容与自身已有记忆的效价（`valence`）方向相反，或置信度处于摇摆区间，不调模型判断真伪，直接由规则产生一个**“求证趋避 Modifier”**注入行为决策层。
  2. 单位在日程空闲时被该 Modifier 牵引，亲自走到 `place_id`（查看现场痕迹）或走到 `公告栏`（读取官方 `Announcement`）。
  3. 一旦进入感知范围成为新的 `witness` 或触发 `AnnouncementRead`，高权重的亲历/官方信息自然覆盖低权重的传言，并发出 `RumorDebunked`。
* **设计价值**：把抽象的“信息纠偏”外显为屏幕上可见的“听闻八卦 $\rightarrow$ 满腹狐疑 $\rightarrow$ 跑去现场围观 $\rightarrow$ 真相大白”的像素小人跑动，全流程 0 模型调用、100% 可回放。

### 2. 空间痕迹的逆向感知：用“残缺事实”激活传播网
《记忆协议》第 11 节将建筑痕迹（`Trace`：焦痕、修补、花环）定义为空间沉积的记忆；《传播设计》将“痕迹”列为保真度低、需推断的第五通道。如何在严守**“不允许凭空编造事实”**的原则下实现“推断”？

* **思想逻辑**：“推断（`inferred`）”不是编造新事实，而是**“合法地丢失 `who` 与具体 `what`，只保留空间与结果的空壳记忆”**。
* **确定性机制**：
  1. 当不在场的单位路过某建筑触发 `CueFired`，若建筑上存在高可见度的新增 `Trace`（如工坊上的焦痕），且该单位记忆库中没有对应的 `event_ref`。
  2. 运行时直接依据后果规则的逆映射，写入一条 `source_mode = inferred`、`detail_level = 1` 的残缺记忆：保留真实事件的 `event_ref` 与 `where`（溯源率依然 100%），但将 `who` 置空，`what` 降级为宽泛类别（如“此处近期发生过变故”）。
  3. 这种“知道出事了但不知道是谁干的”残缺条目天然携带高 `surprise`（惊奇度），按既有权重公式会自动获得高显著度（`salience`），促使小人在进入酒馆等社交场合时优先将其作为话题抛出，在同村亲历者的回应中补全拼图。

### 3. 隐私边界的叙事化：上游任务的“结构化脱敏编译”
《记忆协议》第 14、15 节划定了严格边界：上游 Agent 的真实任务以 `source = agent` 进入世界，但涉及用户的 `private_to_player` 事件绝不能以明文进入单位记忆、气泡或碑文。

* **思想逻辑**：像素世界不需要知道用户在写什么代码或回谁的邮件（那是上游的真相），像素世界只需要感知**“神明降下的劳作在物理与情绪层面的投影”**。脱敏不是打码，而是**剥离业务语义，仅映射工作流拓扑与情绪效价**。
* **确定性机制**：在事件入口处建立一层纯规则的“隐喻转译契约”：
  * **剥离什么**：文件路径、收件人姓名、代码片段、商业数字等一切上游明文字符串，在跨越边界时物理截断，绝不进入世界侧 Event 的 `outcome` 字段。
  * **保留什么**：只将任务的**发生场所**（映射至对应工坊 `place_id`）、**协同角色**（`actors`）、**执行波折度**（重试次数映射为 `conflict` 强度）与**最终验收结果**（准奏/驳回映射为正负 `valence`）写入 `sanitized` 事件。
* **设计价值**：既在物理层面上保证 100% 通过隐私与级联删除测试，又让像素小人的记忆、日记和工坊上的焦痕/花环，真实反映用户与 Personal Agent 协同的历史起伏。

### 4. 传播网络的自平衡：基于预算的退火阻尼
针对两份文档中待调参的各类阈值（显著度门槛 `T_write`、闲话冷却、扇出上限），为防止任务高峰期全村瞬间同质化，或任务低谷期世界陷入死寂：

* **思想逻辑**：遵循《记忆协议》中“预算（Budget）控制”的核心思想，不仅存储有容量预算，**世界的每日信息流动总量也应有带宽预算**。
* **确定性机制**：以天（`world_day`）为单位统计全局传播热度。当当日 `ClaimTold` 累计次数逼近世界总人口的带宽上限时，线性抬高闲话触发的 `salience` 门槛（让小人只聊真正的大事）；当世界连续多日无高优新事件进入时，自然降低 `CueFired` 的回忆门槛，让小人走过老地方时更容易触发对 `long`（周摘要）和 `legend`（传说）的怀旧复述。

## 第二部分：造物主生成 × 控制迭代（外环补充设计）

> **思想锚点**：放弃“一句话无人值守生成完整游戏”的幻想。承认生成模型在几何接缝、长程状态和通用性上的短板，用**“受约束的创世指令 + 可计算的自动门禁 + 把人工修改沉淀为源头规则”**来换取自治等级（L0 $\rightarrow$ L4）的稳步爬升。

### 1. 兑现“收敛条件二”：让人工修改自动编译为源头护栏
《渐进迭代》中提出了最核心的收敛判据：**“人工修改率逐轮下降”**，且**“每次人工介入都必须留下可复用的东西（沉淀成规则、示例或提示模板）”**。

* **思想逻辑**：在工程实践中，人类审校者（Reviewer）最擅长的是“一眼看出哪里不对并顺手改掉”，最不擅长的是“停下来把刚才的修改抽象成一条形式化规则”。如果靠人手写规则，知识复用的飞轮就会因摩擦力过大而停滞。
* **机制设计——差异逆向沉淀（Diff-to-Constraint）**：
  1. 在 L1（逐项确认）和 L2（过检免审、其余人工）阶段，系统不仅记录最终通过的状态，还强制捕获每一次 **`(造物主提议, 人类最终修正)` 的 Diff 对**。
  2. 由独立的**审校角色（Verifier/Reviewer Agent）**在后台分析该 Diff，向人类发起一次低成本的“规则晋升确认”：
     * *当人类手动挪动了地图师生成的建筑位置* $\rightarrow$ 审校提议：“是否将 `铁匠铺与居民区距离 >= 4格` 写入地图师的布局约束检查表？”
     * *当人类删改了史官生成的一段背景故事* $\rightarrow$ 审校提议：“是否将此次修改提取为《世界圣经》的禁用词汇/语气负向示例？”
  3. 人类只需点击一次“固化”，单次的救火动作就正式编译成了下一轮迭代的**前置自动检查项**。只有当自动检查项越积越多，对应模块才具备从 L1 晋升到 L2/L3 的客观基础。

### 2. 绕过模型短板：“骨架确定、皮肤受控、叙事靠沉积”的三层资产观
《可行性评估》坦诚指出了 2026 年模型的边界：静态图与结构化文本强，但**无缝瓷砖接缝、多帧一致动画、长程不漂移**可行性低，建议“用模块化、装饰层绕过”。我们将这一判断与内环的《记忆协议》深度咬合，确立**三层资产解耦原则**：

* **思想逻辑**：不要让概率性的生成模型去干确定性几何与物理该干的事；不要试图用昂贵的逐帧动画去堆砌生动感，而要用**低成本的历史痕迹沉积**去呈现鲜活的世界。

| 资产层级 | 职责边界 | 生成与控制方式 | 对应自治等级 | 核心收益 |
| :--- | :--- | :--- | :--- | :--- |
| **1. 拓扑与骨骼层** | 瓷砖连通掩码、碰撞网格、小人通用动作骨架 | **100% 确定性算法与预制模板**（绝不让 AI 生成接缝与走路帧） | **L4（免审）** | 彻底根除接缝错位与动画闪烁问题，保证物理世界底座坚不可摧。 |
| **2. 风格与组件层** | 建筑静态本体、纸娃娃配饰叠层、严格受限调色板 | **造物主（美术监督）受控生成 + 自动网格吸附与色板量化检查** | **L2（过检免审）** | 验收标准 100% 可计算（色数、尺寸、透明通道、剪影对比），极易自动化放行。 |
| **3. 叙事沉积层** | 焦痕、修补木板、青苔、节日花环、磨损路径、牌匾地名 | **由内环《记忆协议》的 `Trace` 与 `ToponymChanged` 规则实时驱动** | **L3–L4（规则驱动）** | **四两拨千斤**：哪怕两个世界用同一套基础建筑模板，运行 30 天后，因为经历的任务与事故不同，建筑上的痕迹与地名演变也完全独一无二。 |

### 3. 自治爬梯的动态护栏：基于漂移指标的“双向升降级”
《渐进迭代》设计了 L0 到 L4 的能力爬梯，并强调“跑得越久越容易漂移，必须监控不变式被违反的次数与回归集表现”。

* **思想逻辑**：自治等级（Autonomy Level）不应是永久授予的静态头衔，而应是**与实时质量挂钩的动态信用额度**。放权的前提是随时能以极低成本收回权限并回滚状态。
* **机制设计**：
  * **晋升门票**：某个造物主角色（如 `地图师` 或 `史官`）只有在连续 $N$ 轮迭代中，“前置自动检查通过率”高于阈值且“人工修改率”趋近于零，才允许向上爬升一级（如 L1 $\rightarrow$ L2）。
  * **熔断降级**：当处于 L2/L3（免审或抽检）的角色在运行期触发了内环的硬性报警——例如《记忆协议》中的**“摘要实体越界校验拒绝”**连续发生，或违反《世界圣经》不变式——系统自动触发熔断，将其权限降回 L1（强制人工确认），并利用事件日志的分支与级联删除机制（`MemoryDeleted`），一键回滚污染区间，确保主世界时间线永远干净。

### 4. 内外环的终极闭环：内环记忆统计作为外环“导演”的温和传感器
《可行性评估》中定义了**导演（Director）**角色：“按设定包的目标氛围，每天规划一次、注入事件、控制节奏，通过受校验的指令改动世界”。导演该如何感知世界当前需不需要注入事件？

* **思想逻辑**：如果让导演 Agent 每天去读取全量事件日志或所有小人的记忆明文，不仅违背“低成本”原则，还会因上下文过长引发严重的幻觉漂移。**导演只应看“仪表盘”，不应看“监控录像”**。
* **机制设计**：
  1. 每日天界 `DayClosed(day)` 触发内环完成日终整理并抛出 `MemoryConsolidated(holder_id, day, stats)` 后，运行时将全村的 `stats` 聚合成几个纯粹的标量指标：
     * **情绪温度计**：全村当日记忆的平均效价（`mean_valence`）与平均唤醒度（`mean_arousal`）。
     * **社会连通度**：当日传播网络的覆盖率与孤立节点数。
     * **叙事饱和度**：近 7 天是否有新的 `Legend`（传说）或地标痕迹产生。
  2. 外环的 `导演` 每天仅接收这几个数字与《世界圣经》的目标基调做比对。当发现世界长期处于“低唤醒度（沉闷）”或“连续负效价（高压挫败）”时，导演才提交一条参数化的 `创世指令`（如：触发一场集市庆典或降下神明赐福），经审校角色校验不违背世界不变式后，作为标准 Event 注入明日的世界。

## 结语：这套体系真正独特的地方

通过把四份文档收束到上述双环架构中，这个项目最核心的工程壁垒已经非常清晰：
它**既不是一个完全写死的传统模拟游戏**（因为它有造物主引擎源源不断地将设定与上游真实任务编译进世界），**也不是一个放任 LLM 自由发挥却在三天后崩坏的 AI 玩具**（因为一切记忆皆有事件出处、一切传播皆受视角约束、一切生成皆受不变式门禁拦截）。**用确定性的系统底座去驯服概率性的多 Agent 创造力**，这就是整套设计最坚实的灵魂。
