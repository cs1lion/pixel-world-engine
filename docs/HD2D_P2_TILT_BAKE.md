# HD-2D P2：纯烘焙移轴（第一版）

状态：**里程碑版**，只在 `?dof=on` 时生效；`?dof=off`（默认）不创建任何对象、不申请任何纹理。
设计原文是仓库外的 HD-2D 技术路线 §13，这里只记录落地后的实现口径与实测。

## 1. 管线

1. **S-0 断言**（`dof-view.ts` 第一行逻辑）：地形贴图的源必须是 `HTMLCanvasElement`，
   否则直接抛错、整条路径停掉。Phaser 升级若把 `generateTexture` 换成 GPU readback，这里先红。
2. 离屏 canvas（世界全尺寸）→ `drawImage(地形纹理)` → `getImageData`。
   **闭包只有地形一层**：轨道 / 铺装 / 水洼 / 潮位都在糊图之上，保持清晰。
3. `boxBlurRGBA`：可分离整数 box；横 pass 存 32 位原和，纵 pass 唯一一次除法；边缘复制；
   `k = 2r+1` 恒为奇数；单次迭代。alpha 先扫一遍，任何 ≠ 255 直接失败（M-15）。
4. 双缓冲 `world-blur-a/b`：写非当前图 → `putData` → `refresh` → `setTexture`。
   **永不 `textures.remove`**（同 key 重建会停在上一版，`bake.ts` 的老坑）。
5. 版本向量 `(terrainVersion, structuresVersion)`：帧首比对，变化才重建。
   潮位 / 天气 / 雾 / 人物都不在向量里——否则糊图过期节奏会等于潮位节奏。
6. 行裁切窗：`focusWindow(worldView.y, zoom, height)`，裁切高 = 焦点带高 − 1（隔离行），
   1 px 硬边、不做渐变。`worldView.y` 是视野上沿，不是 `scrollY`（zoom ≠ 1 时两者不同）。

## 2. 与设计原文的一处算术订正

§13.3.4 写的是 `(sum + r) / k`。实现是「横 pass 存 k 个像素的原和」，所以纵 pass 的除数
必须是 **k²**（舍入偏移 `floor(k²/2)`），否则亮度会被放大 k 倍。常数场测试锁的就是这条：
k=3/5/7 输入输出逐字节相同。

## 3. 档位与核

- 焦点带高 = `height / (2 × zoom)`：zoom 1 → 160，zoom 2 → 80。
- zoom 1.5 / 3 不支持：整层隐藏，不猜。
- 核首档 **B1：r = 1（k=3）**。§13.3.2 明确要求「先看这一档能否读成焦外」，不达标再换 B2，
  不允许叠加迭代。

## 4. 深度位置与已知代价

`DOF_DEPTH = -5`：压在地形（-10）之上、痕迹（0）/ 铺装（1）/ 水洼（2）/ 潮水（3）之下。

- 潮位、轨道、铺装在糊图之上 → 远带里它们保持清晰，但**不会消失**（见下）。
- 建筑 / 摆件 / 人物在 1000 以上 → 远带里的静态结构**仍然清晰**。
  这是第一版**未闭合**的部分（见 §6），不是被忽略的 bug。

> 第一版曾把糊图放在潮水与铺装之间（2.9）：结果码头轨道（depth 0）被盖住，
> 远带里整条轨道凭空消失。宁可让结构「硬」，也不能让内容「没」——深度因此让位到地形之上。

## 5. 实测（灯潮界 64×48 格 = 1024×768 px，正午、潮位 0、无雨、世界冻住）

| C1b 隔离行（1 world px） | **0**（1,920 px） |
| C3 远景带 exact / visible | **37.17% / 34.30%**（maxΔ 62） |

## 6. 未闭合项

1. **S-4：静态摆件 / 建筑未进闭包。** 它们 depth ≥ 1000，在糊图之上，远带里保持清晰。
   要做全，需要「烘进闭包 + 按焦线隐藏完全落在远带里的那部分」两步，且不能碰内景模式的可见性。
   第一版的取舍是「宁可硬、不能没」：结构清晰但完整，而不是被糊图盖掉或凭空消失。
2. **C2（硬件 / SwiftShader 双后端 0 diff）**：本机只有 SwiftShader，留给 CI 两台执行器。
3. **166 张基线**：本树没有基线夹具集（在另一条工作线上），本笔只能从结构上保证默认路径零新增。
