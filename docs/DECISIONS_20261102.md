# 2026-11-02 代理代行决策记录

用户授权代理在 8 小时内按既定路线连续执行，并允许代为做决定。本文件只记**需要产品判断、
但用户已提前给出原则（可回退 + 精品化 + 不造假）**的岔路，以及选择与理由，供用户醒来复核。
纯机械的改动（注释纠错、坐标随内容移动）不在此列。

## T2 真实时钟

### D1. 真实时钟是显式开关，默认仍走加速模式

- 选择：`?clock=real` 才切 1:1；默认仍 `timeScale=6`。
- 理由：改变默认会同时改变演示观感、截图基线与所有浏览器回归的节奏，属于不必要的连带
  风险。真实时钟要能被验收，不要求它成为默认。
- 可回退：删掉 URL 参数那一支即可，默认路径一行未动。

### D2. 锚点只用于新世界，读档不改写世界时钟

- 选择：新世界把 `now` 锚在「本地今天已过了多久」；读档沿用存档里的 `world.now`。
- 理由：存档里的 `now` 是世界自己的事实（ADR_SAVE §1）。为了对齐日界去改写它，会让
  记忆与编年史的时间线出现回跳；那比「老档的日界不落在午夜」更难解释。
- 代价：老档在真实时钟下仍按它自己的日界关账，直到玩家开新档。已在代码注释写明。

### D3. 离线超过 7 天：合并不是重放

- 选择：跨 1–7 天逐日关账；超过 7 天只关一次，记 `skippedDays`。
- 理由：把 10 天的逐拍行为压进一帧补跑，补出来的不是「中间发生了什么」，是假的。
  关账仍走 `world.dayClosed` → `onVitals` → `stepCreatorDayClosed` 这条既有路径。
- 代价：中间那些天在编年史上表现为「一段时间过去了」，不是十份完整日报。

### D4. 墙钟回拨暂停后不自动恢复

- 选择：回拨超过 5 分钟即暂停推进，状态行明说；提供 `resume()`，但没有自动恢复。
- 理由：静默把 `now` 改回去会让世界进入一个无法回放的时刻；暂停是可解释的，
  自动改写不是。自动恢复需要一个人来判断「现在几点了」，本阶段不替人判断。
